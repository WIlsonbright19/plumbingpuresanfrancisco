# Plumbing Pure

Website for Plumbing Pure, serving San Francisco and Marin County.

## Local Development

Requires Node.js.

```sh
npm install
npm run dev
```

## Build and Deploy

```sh
npm run build
```

Deploy the generated `dist` directory to any static web host. The site does not require a server runtime or environment secrets. Relative asset paths support deployments from a domain root or a subdirectory.
